# Ruchita Suthar Portfolio

A polished fashion designer portfolio built with React, Vite, and Framer Motion. The site is designed for a premium editorial look, structured for easy content updates, and optimized for responsive viewing across desktop and mobile devices.

## Features

- Responsive single-page portfolio experience
- Centralized editable content file for all portfolio data
- Project detail pages and modal case-study previews
- Motion-enhanced section transitions and soft editorial styling
- Contact form that opens a pre-filled email draft
- SEO metadata and social sharing setup

## Tech Stack

- React
- Vite
- React Router
- Framer Motion
- CSS custom styling

## Getting Started

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Build for production:
   npm run build
4. Run lint checks:
   npm run lint

## Editable Content

All portfolio content is centralized in:

- src/data/portfolioData.js

Update the personal profile, contact details, work history, project entries, testimonials, and SEO metadata from this file without editing the main layout components.

## Project Structure

- src/App.jsx — page structure and sections
- src/App.css — styling and responsive layout
- src/data/portfolioData.js — all editable portfolio content
- src/assets — local SVG artwork and visuals

## Deployment

After customizing the contact URLs and profile details, deploy the built app using any static hosting provider that supports Vite builds, such as Vercel, Netlify, or GitHub Pages.
